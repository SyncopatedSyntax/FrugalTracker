# FrugalTracker

Offline-first personal expense tracker PWA (React + Vite + TS + Dexie/IndexedDB + Tailwind). See `README.md` for features and stack details.

## Session log convention

`prompt.md` at the repo root is a chronological log of the user's prompts in this project and a short summary of what was delivered for each. Maintain it as follows:

- **After each user prompt** that results in a change or a decision, append a new numbered entry to `prompt.md`: the prompt text (verbatim or lightly trimmed if very long) as a blockquote, followed by a **Result:** summary of what was done.
- **Whenever committing and pushing** (whether requested explicitly or triggered by a repo hook), make sure `prompt.md` is up to date first and include it in that commit.
